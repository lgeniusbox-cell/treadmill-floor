Test goal

Determine whether media-stream reads, response-body consumption, MSE appends, or media-element operations occur in the main page realm. If the logs remain empty for these APIs while YouTube plays inside its iframe, that is evidence these operations are not exposed through the main page's JavaScript prototypes—not proof that no media stream exists.
