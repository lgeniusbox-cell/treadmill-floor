YouTube Media Lifecycle Inspector

Instrument media API activity and correlate stream reads, MSE appends, buffer ranges, and playback state. This page does not claim to bypass the browser's cross-origin isolation.

Important cross-origin limitation

Hooks installed by this page run in the parent page only. YouTube's player executes in a separate cross-origin iframe, so this HTML alone cannot patch the iframe's prototypes or identify its internal JavaScript caller. To inspect the actual YouTube lifecycle, load the video, select the YouTube iframe execution context in DevTools Console, and run the iframe probe provided below before reloading/restarting playback. For earliest possible instrumentation, use Chrome DevTools Protocol or a browser extension with document-start injection.
